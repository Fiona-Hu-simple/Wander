## 注册连接故障复查

实际发现前端 5173 正常运行、后端 3000 未监听；`.env.local` 仍指向 `http://localhost:3000/api`，注册因无法连接后端失败。将本地地址改为 `/api`，根目录 `npm run dev` 改为同时启动前后端。登录及注册区分连接失败、超时和业务错误。新增 `npm run test:dev`，用内存数据库验证通过 Vite 代理注册返回 201、登录返回 200、身份查询返回 200；实际 5173 与 3000 健康检查也均为 200。

本次检查前后端源代码、路由、组件生命周期、请求处理、配置及资源引用；修复没有覆盖用户原有的 `index.html` 修改和未跟踪的 `src/views/hsw.vue`。

## 登录实现

1. Vue 登录表单通过 Axios 调用 `POST /api/auth/login`。
2. Express 使用 SQLite 参数化查询查找用户，通过 bcrypt 对比密码。注册时保存 bcrypt 哈希，成本参数为 10，数据库不保存明文密码。
3. 后端使用 `JWT_SECRET` 签发 HS256 JWT，有效期 7 天，包含用户 ID 和用户名。
4. 前端在 localStorage 保存 token、userId、username，受保护 API 使用 `Authorization: Bearer <token>`。
5. 新增 `GET /api/auth/me`，进入受保护路由前由后端验证签名、有效期和用户是否仍然存在。前端路由守卫负责页面导航，后端鉴权中间件负责接口权限。

## 已修复

| 问题 | 修改 |
| --- | --- |
| 路由只检查 token 是否存在，过期或伪造 token 仍可进入页面 | 后端验证 `/auth/me`；失效后清理会话并回登录页；网络错误单独提示 |
| 401 混淆密码错误、登录失效和 AI 服务认证错误 | 登录错误在表单显示；受保护请求失效返回登录；上游失败转换为 502 |
| 没有退出登录、个人页显示固定用户名 | 个人页显示登录用户，支持清理本机会话并退出 |
| 登录重复提交、注册成功后再次提交、离开页面后延迟跳转 | 提交锁、按钮状态、异步结果检查和定时器清理 |
| 注册/登录参数类型未校验，bcrypt 长密码存在截断问题 | 用户名统一 trim，验证类型和长度，密码最多 72 UTF-8 字节 |
| 并发注册相同用户名返回 500 | 数据库唯一约束冲突统一返回 409 |
| 登录、注册和 AI 请求没有频率控制 | 单 IP 限流；登录及聊天每分钟 20 次，注册每分钟 10 次 |
| 聊天记录跨账号共用，KeepAlive 缓存可保留上个账号状态 | 聊天存储按用户 ID 分开；账号变化时重建缓存 |
| 开始流式回复后解除发送锁，可并发请求并覆盖消息 | 发送锁保持到整个流结束，消息绑定原对话 |
| 聊天未检查 HTTP 错误、最后一行和流提前结束 | 检查响应状态与格式，处理尾行和 `[DONE]`，展示错误 |
| 聊天缺少超时、取消、代理消息校验和慢客户端处理 | 前后端 120 秒超时；页面卸载或客户端断开时取消；释放读取器并处理写入背压 |
| 地图弹窗及标记直接拼接用户输入 | 通过 DOMPurify 清洗 HTML |
| 地图搜索旧请求覆盖新结果、坐标 0 被误判、重复地点导致标记错乱 | 取消旧搜索并核对查询；验证有限数值与范围；阻止同名重复地点 |
| 地图缓存恢复时尺寸不正确，地图和定时器未完整清理 | 激活时更新尺寸，停用/卸载时清理搜索、地图及定时器 |
| 相册不同目的地都显示三亚 | 根据目的地参数显示对应标题和占位卡片 |
| 行程页重叠显示状态栏、页面组件名称冲突 | 移除重复状态栏并更正页面名称 |
| 登录装饰方块遮挡输入、按钮 | 装饰方块不接收指针事件 |
| 缺少 API 默认地址和开发代理、生产 CORS 固定 | 默认 `/api`，Vite 代理到 3000，CORS 可通过环境变量配置 |
| 异常 JSON 和超大请求返回不统一 | JSON 错误返回 400，超过 128 KiB 返回 413 |
| 后端 .env 可能提交入库 | 加入忽略规则，提供无真实凭据的配置模板 |

- 未进行浏览器端交互回归，也未调用真实 DeepSeek 或地图服务；外部服务连通性、浏览器视觉效果需实际启动后确认。

## 保留的产品边界

- 行程、统计、新闻和相册图片多数为演示数据；订单、收藏、设置、分享、规划和相册新增等按钮还没有对应业务。实现这些功能需要明确产品需求，本次没有虚构后端功能。
- 地图地点仅保留于当前页面缓存，没有持久化到数据库。
- 原来的 `wander_conversations` 聊天记录无法确定所属账号，因此保留原数据、不自动复制到任何账号。账号专属 `wander_conversations:<userId>` 已支持一次性导入 SQLite；服务器保留导入凭据，防止重复导入和删除后复活。
- 聊天记录、草稿和当前会话已改为 SQLite 存储，接口根据 JWT 验证的用户进行归属检查。localStorage 只保留迁移备份、未同步草稿和待确认请求标识。JWT 仍是 Bearer 令牌；退出只清理本机会话，已签发令牌在过期前仍可能有效。
- 限流存储在单进程内存中，重启会清空，多实例部署需要共享存储。
- 用户未跟踪的 `src/views/hsw.vue` 是练习代码，包含未定义的 `box`、`_`、`mouseMove`，没有接入路由；保持原文件，接入应用前需要整理。

第一版使用单个 API 进程。客户端断开时取消生成并保存部分内容；后端重新启动时将遗留的生成中消息标记为中断，不自动继续生成。异常强制退出可能损失最后一次保存之后的片段。
